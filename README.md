# Kongyo GitHub Custom

A pluggable browser extension that adds custom enhancements to GitHub. Built as
a long-running module host: every feature lives behind its own toggle on the
options page, and new modules slot into the same panel without disturbing the
others.

**Module status**

| Module       | State    | What it does                                                                                         |
| ------------ | -------- | ---------------------------------------------------------------------------------------------------- |
| Wiki Buttons | Shipping | Injects DeepWiki and Code Wiki shortcuts into every GitHub repository page's `pagehead-actions` bar. |

The Wiki Buttons module is a unified port of two reference extensions
([github-deepwiki-button](https://github.com/yamadashy/github-deepwiki-button) +
[github-code-wiki-button](https://github.com/yamadashy/github-code-wiki-button)),
rewritten in TypeScript with a settings UI on top.

## Stack

- TypeScript (modern strict — `target: esnext`, `noUncheckedIndexedAccess`,
  `exactOptionalPropertyTypes`, `verbatimModuleSyntax`)
- Vite + [@crxjs/vite-plugin](https://github.com/crxjs/chrome-extension-tools)
  for MV3 packaging and HMR
- React 18 for the options UI
- Prettier + Oxlint
- `chrome.storage.sync` for cross-device settings

## Scripts

```bash
npm run dev          # Vite dev server + HMR (load dist/ as unpacked)
npm run build        # tsc --noEmit && vite build → dist/
npm run typecheck    # tsc --noEmit
npm run lint         # oxlint --silent
npm run lint:strict  # oxlint --deny-warnings (CI)
npm run lint:fix     # oxlint --fix
npm run format       # prettier --write .
npm run format:check # prettier --check .
npm run package      # build + write release/<name>-<version>.zip for store upload
```

## Manual testing

1. `npm install`
2. `npm run build`
3. Open `chrome://extensions`, flip on **Developer mode**, click **Load
   unpacked**, and pick the `dist/` directory.
4. Visit any GitHub repository (e.g. `https://github.com/yamadashy/repomix`) —
   **DeepWiki** and **Code Wiki** buttons should appear in the same row as
   Watch / Fork / Star.
5. Click the extension's options entry (`chrome://extensions` → **Details** →
   **Extension options**) to open the settings page in a new tab. Toggling any
   switch instantly updates every open GitHub tab.

### Things to verify by hand

- SPA navigation: click a file inside a repo, then **Code** to go back — the
  buttons must remain in place.
- Disable both Wiki toggles: the buttons disappear from every open GitHub tab
  within ~200 ms.
- Toggle "Open in new tab" off: the link should navigate in the current tab.
- Click **Restore defaults** in the options page: both toggles flip back on.

## Publishing to the Chrome Web Store

```bash
npm run package
# → release/kongyo-github-custom-<version>.zip
```

Upload that ZIP via the Web Store developer console. Bump `version` in
`package.json` before each store submission — the manifest pulls its version
straight from there.

## Adding a new module

1. Add a key + definition to `src/lib/wikis.ts` (or extract a more general
   module registry alongside it).
2. Extend `Settings` and `DEFAULT_SETTINGS` in `src/lib/settings.ts`.
3. Render the new module's card inside `src/options/App.tsx` and (if it injects
   UI) wire it into `src/content/index.ts`.
4. Update `_locales/*/messages.json` with the new strings.
